{# The two page-level navigation controls, so that "Back" means one thing. `back_link` returns you to the page you came from and is the ONLY place the word "Back" is allowed. Its target comes from `resolve_back()`, which is what guarantees the label names the actual destination — a link reading "Back to Players" that lands on the player list you were never on is the bug this file exists to prevent. `breadcrumbs` says where a page sits in the hierarchy. It is not history, so it never says "Back". Use it on hub and index pages, which you arrive at from anywhere; use `back_link` on leaf pages you drill into. A forward navigation ("View the draft board") is a plain link and belongs in neither macro. #} {% macro back_link(target, extra_class="") -%} Back to {{ target.label }} {%- endmacro %} {# `trail` is a list of {label, url} dicts, outermost first. The last entry is the current page and is rendered as plain text — linking a crumb to the page already on screen is the other half of the same dishonesty. #} {% macro breadcrumbs(trail, extra_class="mb-3") -%}
{%- for crumb in trail %} {%- if not loop.last and crumb.url %} {{ crumb.label }} {%- else %} {{ crumb.label }} {%- endif %} {%- endfor %}
