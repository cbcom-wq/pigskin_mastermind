📐 MC Engine Reference

How each hyper-parameter affects the Monte Carlo simulation pipeline.

🏃 Touch Volume

touch_std_fraction — Width of the Normal distribution for touch counts. Higher = more game-to-game variance.

trend_touch_weight — How strongly a player's recent trend score shifts expected touches up or down.

momentum_touch_weight — How strongly team offensive momentum adjusts expected touches.

⚡ Efficiency

matchup_weight — Scales the offense-vs-defense gap's effect on per-touch fantasy points.

position_rank_divisor — Larger value = smaller positional matchup bonus. Controls how much a weak D helps.

efficiency_std_fraction — Width of the Normal distribution for per-touch efficiency. Higher = more boom/bust.

🏈 Touchdowns

base_td_lambda — Poisson baseline λ before skill/offense scaling. Higher = more TDs on average.

skill_td_weight — How much player skill level multiplies the TD rate above baseline.

offense_td_weight — How much team offense level multiplies the TD rate above baseline.

🎲 Simulation

injury_usage_factor — When an injury event fires in a simulation, touches are multiplied by this (0 = out, 1 = no effect).

boom_threshold — Points above which a simulation counts toward boom probability.

bust_threshold — Points below which a simulation counts toward bust probability.

simulations — Number of independent MC iterations. More = smoother distribution, slower run.
